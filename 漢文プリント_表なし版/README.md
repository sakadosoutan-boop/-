# 漢文プリント（表なし版）

表をいっさい使わず、**段落と段組みだけ**で組んだプリントです。

- 行間は段落の設定そのままなので、Word の「段落」ダイアログ一か所で効きます
- 入りきらない文字は折り返されます。表のように**黙って消えることはありません**
- 絶句なら「詩題・作者・四句」の六行が、紙の幅いっぱいに等間隔で並びます

## ファイル

| ファイル | 中身 |
| --- | --- |
| `content_sohatsu.py` | 教材の文字と文字の大きさ。**次の教材はこれをコピーして書き換える** |
| `build.py` | データ → 解答版・生徒版を書き出す |
| `sheet.py` / `oxml.py` | 仕組み（紙面の寸法と、Word XML の組み立て） |
| `preview.sh` | できあがりを画像にして目で確かめる（LibreOffice が要ります） |
| `check.py` | 1 枚に収まっているか、紙をどこまで使えているかを調べる |

```bash
python3 build.py content_sohatsu.py
python3 check.py 早発白帝城_解答版.docx content_sohatsu.py
./preview.sh 早発白帝城_解答版.docx preview        # preview/p1.png を開く
```

## 紙面の組み立て

A4 横・縦書きです。縦書きでは段区切りが右から左へ並ぶので、一枚はこうなります。

```
 ←左                                                              右→
 ┌─────────┬─────────┬───────────────────────┬────────────┐
 │  語注   │  設問   │  訓読文（上段 56mm）   │ 見出し     │
 │（1段）  │（1段）  │ ──────────────────── │ 指示文     │
 │         │         │ 書き下し・訳（下段120mm）│ 記名      │
 └─────────┴─────────┴───────────────────────┴────────────┘
   枠あり    枠あり          枠あり                枠なし
```

- 段組みにしているのは**本文だけ**。見出し・記名・設問・語注は 1 段です
- 上段と下段は**同じ行間**なので、句と訳が横に並んで対応します
- 生徒版の下段には、書き込む位置を示す薄い縦罫が**行数ぶん**入ります

## 飾り枠

角丸の図形で、**レイアウトは「背面」・文字の折り返しなし**。文字の送りには
影響しません。`content` 側の `FRAMES = 'none'` で枠なしにもできます。

枠の位置は、語注や設問が実際に何行になったかで決まります。`build.py` は
LibreOffice があれば一度刷ってそれを測り、測った値でもう一度書き出すので、
枠は文字にぴったり沿います。LibreOffice がなければ見積もりで置くため、
枠が数ミリ外側に立つことがあります（印刷には支障ありません）。

> **ひとつだけご確認を。** 縦書きでは図形の座標軸が 90 度回ります。
> こちらの確認は LibreOffice でしかできないため、Word で開いたときに枠が
> ずれていたら教えてください。`oxml.py` の `shape()` の 2 行を入れ替えれば
> 直ります。それも面倒なら `FRAMES = 'none'` で枠なしにできます。

## 文字の大きさと行間

文字の大きさは `content_sohatsu.py` に書きます。

| 名前 | 既定 |
| --- | --- |
| 見出し（`head` の第 2 要素） | 12pt |
| `upper_size`（訓読文） | 18pt |
| `lower_size`（書き下し 16pt／現代語訳 10.5pt） | 段の高さに収まる大きさ |

`build.py` は、一行が段の高さを超えると
`! 上段からはみ出します` と知らせます。そのときは文字を小さくするか、
`sheet.py` の `BAND_TOP` / `BAND_BOT` で段の高さを変えてください。
ルビつきの字は、ルビが入るぶん幅を取ります（`{朝｜あしたニ}` は 朝 一字の
倍近く）。その分も数えたうえで判定しています。

行間は `sheet.py` の先頭です。

| 名前 | 意味 | 既定 |
| --- | --- | --- |
| `PITCH_HEAD` | 見出し・記名 | 560（10mm） |
| `PITCH_ASIDE` | 設問・語注 | 340（6mm） |

本文の行間だけは**自動**です。見出しと語注・設問が使った残りを句数で割るので、
語注が増えれば詩が詰まり、減れば広がって、いつでも紙の幅いっぱいになります。

## データの書き方

| 記法 | 意味 |
| --- | --- |
| `{漢｜かん}` | ルビ（親字｜読み） |
| `^{二}` | 返り点・小書きの送り仮名 |
| `《…》` | 解答（解答版は赤字／生徒版は薄い罫線の空欄） |
| `*…*` | 太字（見出し） |
| `#…#` | 語注の見出し語（正楷書体・藍・太字） |

`KAKIKUDASHI` と `YAKU` の `None` は、上段の「作者」に対応する空行です
（生徒版ではここにも罫線が入ります）。上段と下段の行数をそろえてください。

散文（「先従隗始」など）も同じ仕組みで組めます。`upper` / `lower` を
十行にすれば、そのぶん本文の行間が詰まって収まります。

## 確認できていないこと

プレビューは LibreOffice で作っています。Windows の「UD デジタル教科書体 N」
「HG正楷書体-PRO」が入っていない環境では別の書体に置き換わるため、折り返しの
位置が Word と少しずれます。最終確認は Word の印刷プレビューでお願いします。
