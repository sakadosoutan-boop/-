# 漢文プリント（表なし版）

表をいっさい使わず、**段落と段組みだけ**で組んだプリントです。

- **行間はすべて「1 行」**（Word の既定）。列の間隔は*段落後の間隔*で開けています
- 入りきらない文字は折り返されます。表のように**黙って消えることはありません**
- 絶句なら「詩題＋作者・四句」の五行が、紙の幅いっぱいに並びます

## ファイル

| ファイル | 中身 |
| --- | --- |
| `content_sohatsu.py` | 教材の文字と文字の大きさ。**次の教材はこれをコピーして書き換える** |
| `build.py` | データ → 解答版・生徒版を書き出す |
| `sheet.py` / `oxml.py` | 仕組み（紙面の寸法と、Word XML の組み立て） |
| `preview.sh` | できあがりを画像にして目で確かめる（LibreOffice が要ります） |
| `check.py` | 1 枚に収まっているか、紙をどこまで使えているかを調べる |
| `overflow.py` | 版面からはみ出した文字がないかを調べる |

```bash
python3 build.py content_sohatsu.py
python3 check.py    早発白帝城_解答版.docx content_sohatsu.py
python3 overflow.py 早発白帝城_解答版.docx 早発白帝城_生徒版.docx
./preview.sh 早発白帝城_解答版.docx preview        # preview/p1.png を開く
```

## 紙面の組み立て

A4 横・縦書きです。縦書きでは段区切りが右から左へ並ぶので、一枚はこうなります。

```
 ←左                                                              右→
 ┌─────────┬─────────┬───────────────────────┬────────────┐
 │  語注   │  設問   │  訓読文（上段 60mm）   │ 見出し     │
 │（1段）  │（1段）  │ ──────────────────── │ 記名       │
 │         │         │ 書き下し・訳（下段112mm）│           │
 └─────────┴─────────┴───────────────────────┴────────────┘
   枠あり    枠あり     本文全体を 1 つの枠で囲む   枠なし
```

- 段組みにしているのは**本文だけ**。見出し・記名・設問・語注は 1 段です
- **訓読文（上段）は先生が作った版のまま**。文字も大きさも触りません
- **書き下し・訳（下段）だけ、罫線を格子（マス目）にしました**。1 文字ずつ
  枠で囲んだセルが縦に並び、原稿用紙のように書き込めます。解答版はマスの中に
  赤字で解答が入り、生徒版は同じマス数の空欄になるので、行の深さはそろいます
- 下段の行は上段と**同じ間隔**なので、マス目の列がそれぞれの句の真下に並びます
- **本文（訓読文＋書き下し・訳）はまとめて 1 つの飾り枠で囲み**、設問・語注は
  それぞれ別の枠にしました
- 記名欄は見出しのすぐ左、**下詰め**。下に 39mm 空けてあります（`NAME_TAIL`）
- 天 15mm・地 18mm・左右 16mm。段の足元にも `ASIDE_TAIL` / `BODY_TAIL` 分の
  余白を残してあるので、語注の最後の字が紙の端に触れません

### マス目のしくみ（文字囲み線）

表は使わず、**1 文字ずつに「文字の囲み線」を付けて**並べています。ただし
Word は同じ書式の枠が隣り合うと 1 つの外枠に融合してしまうため、そのままでは
マス目ではなく細長い 1 本の箱になります。隣り合うマスの線の太さを
0.5pt/0.625pt でわずかに変えて融合を防いでいます（印刷では見分けが付きません）。

## 行間と間隔

行間はどの段落も「1 行」です。列の間隔は `sheet.py` の 段落後の間隔 で開け、
以前より詰めています。

| 名前 | 意味 | 既定 |
| --- | --- | --- |
| `GAP_HEAD` | 見出し・記名 | 140（2.5mm） |
| `GAP_UPPER` | 訓読文（下段もこれに合わせる） | 170（3mm） |
| `GAP_ASIDE` | 設問・語注 | 紙幅に合わせて自動（上限 480） |

下段の間隔は、上段と同じ列の間隔になるよう `gap_for()` が逆算します。
文字の大きさを変えても答えは句の真下に来ます。

## 1 枚に収める仕組み（自動で縮める）

`build.py` は書き出す前に、まず**紙に入るかを計算だけで確かめ**（レンダリング
なしの見積もり）、入らなければ次の順で自動的に文字を縮めます。**訓読文
（本文）だけは、この処理でも一切触りません。**

1. 書き下し・訳のうち **1 行だけ長すぎて折り返してしまう行**があれば、その
   行の大きさだけを縮める（上段と下段がずれる原因になるので最優先）
2. 設問・語注の大きさを少しずつ縮める
3. それでも足りなければ書き下し・訳の大きさを縮める
4. 最後にタイトルの太字部分を縮める（10.5pt まで）

そのうえで実際に LibreOffice で組んでみて、**それでもページが増えてしまったら
さらに同じ順で縮めて刷り直します**（Word の実際の書体はここより少し幅を取る
ことがあるため、見積もりには 18% の余裕を持たせています＝`SAFETY`）。

## 文字の大きさ

`content_sohatsu.py` に書きます。

| どこ | 既定 |
| --- | --- |
| 見出し | 12pt |
| `upper_size`（訓読文） | 18pt。**自動では縮めません** |
| `lower_size`（書き下し・現代語訳） | 段の高さに収まる大きさ。足りなければ自動で縮む |

訓読文（`upper_size`）の一行が段の高さを超えると `build.py` が
`! 上段からはみ出します` と知らせます。この行だけは自動調整の対象外なので、
気になる場合は `content_sohatsu.py` の文字を削るか、`sheet.py` の
`BAND_TOP` を広げてください。ルビつきの字はルビの分だけ幅を取ります
（`{朝｜あしたニ}` は朝 一字の倍近く）。その分も数えたうえで判定しています。

## 飾り枠

角丸の図形で、**レイアウトは「背面」・文字の折り返しなし**。文字の送りには
影響しません。`content` 側の `FRAMES = 'none'` で枠なしにもできます。

一枚につき枠は 3 つです。

1. **本文全体**（訓読文＋書き下し・訳を 1 つの枠で）
2. 設問
3. 語注

枠の位置は、それぞれの中身が実際にどこまで届いたかで決まります。`build.py`
は LibreOffice があれば下書きを二度刷り、一度目で語注の間隔を紙幅に合わせ、
二度目で各ブロックの位置を測って枠をそこに置きます。

> **座標の向きについて。** Word はページ基準の図形をふつうの紙の座標で
> 読みますが、LibreOffice は縦書きのとき二つの軸を入れ替えて読みます。
> ファイルは **Word に合わせて**書き出しているので、`preview.sh` の画像では
> 枠だけ別の場所に出ます。枠の位置を目で確かめたいときは
> `oxml.py` の `SHAPE_AXES` を `'preview'` にしてください。

## データの書き方

| 記法 | 意味 |
| --- | --- |
| `{漢｜かん}` | ルビ（親字｜読み） |
| `^{二}` | 返り点・小書きの送り仮名 |
| `《…》` | 解答（解答版は赤字／生徒版は空欄） |
| `*…*` | 太字 |
| `~…~` | 少し小さく（詩題に添える作者名など。`SMALL_RATIO` で 0.58 倍） |
| `#…#` | 語注の見出し語（正楷書体・藍・太字） |
| 見出しの先頭 `@` | その行を記名欄として下詰めにする |

`upper` と `lower` は**行数をそろえて**ください。答えが句の真下に来ます。

散文（「先従隗始」など）も同じ仕組みで組めます。`upper` / `lower` を
十行にすれば、そのぶん間隔が詰まって収まります。

プレビューは LibreOffice で作っています。Windows の「UD デジタル教科書体 N」
「HG正楷書体-PRO」が入っていない環境では別の書体に置き換わるため、折り返しの
位置が Word と少しずれます。最終確認は Word の印刷プレビューでお願いします。
