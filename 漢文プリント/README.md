# 漢文プリント テンプレート一式

先生が手作業で仕上げてくださった完成版を**そのままテンプレート化**したものです。
版面・表組み・書体サイズ・図形（巻物・角丸枠）・イラストはすべて完成版から
そのまま引き継いでいるので、作り直しても体裁が崩れません。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `template.docx` | 体裁本体。表組み・図形・イラスト・書体設定を持つ。**直接編集しない** |
| `content_senju_kaishi.py` | 「先従隗始」（散文）の文字だけを入れたデータ |
| `content_sohatsu_hakuteijo.py` | 「早発白帝城」（漢詩）の文字だけを入れたデータ。**次の教材はどちらかをコピーして書き換える** |
| `build.py` | テンプレート＋データ → 解答版・生徒版を書き出す |
| `tplkit.py` / `content_io.py` | 仕組み（差し込み位置の特定と、文字の書き出し） |
| `preview.sh` | できあがりを画像にして目で確かめる |
| `verify.py` | 欄からはみ出して**印刷されなかった文字**がないか調べる |
| `budget.py` / `ruler.json` | 各欄に入る文字数の実測値と、それとの比較 |
| `overlap.py` | 文字どうしが重なって黒くつぶれていないか調べる |

## 使い方

```bash
python3 build.py content_senju_kaishi.py        # 『十八史略』「先従隗始」
python3 build.py content_sohatsu_hakuteijo.py   # 李白「早発白帝城」
```

同じフォルダに 2 つずつできます。

- `先従隗始_解答版.docx` … 解答を赤字で印刷
- `先従隗始_生徒版.docx` … 同じ紙面で解答部分だけ空欄

別の教材を作るときは content ファイルをコピーして中身を書き換え、
`NAME` を変えてから同じコマンドを実行してください。

## 刷る前の確認

縦書きの欄は、入りきらない文字を折り返してくれません。**はみ出した分は
黙って印刷されない**ので、書き換えたら必ず次の順で確かめてください。

```bash
python3 budget.py content_sohatsu_hakuteijo.py     # 入る字数を超えていないか
python3 build.py  content_sohatsu_hakuteijo.py
python3 verify.py 早発白帝城_解答版.docx content_sohatsu_hakuteijo.py
python3 verify.py 早発白帝城_生徒版.docx content_sohatsu_hakuteijo.py
./preview.sh 早発白帝城_解答版.docx preview          # preview/p1.png … を開く
```

`verify.py` が `0 of 132 slots lose their tail` と出れば、全部の文字が
紙に載っています。

※ プレビューは LibreOffice で作るので、Windows の
「UD デジタル教科書体 N」「HG正楷書体-PRO」が入っていない環境では別の書体に
置き換わります。行の折り返し位置が Word と少しずれることがあるので、
最終確認は Word の印刷プレビューでお願いします。
（LibreOffice では 1 枚ごとに白紙が 1 ページ挟まって見えますが、これは
テンプレート本体でも同じで、Word では出ません。）

## データの書き方

文字だけを書きます。書体・サイズ・行間・色は template.docx 側が持っています。

| 記法 | 意味 | 例 |
| --- | --- | --- |
| `{漢｜かん}` | ルビ（親字｜読み） | `{隗｜くわい}` |
| `^{二}` | 返り点・小書きの送り仮名 | `{招｜カントス}^{二}` |
| `《…》` | 解答（解答版は赤字／生徒版は空欄） | `（《まる一年》）` |
| `*…*` | 太字 | `*次の訓読文を…*` |
| `#…#` | 句法名（正楷書体・藍・太字） | `#使役#` |
| 改行 | 同じ欄の中での改列 | 現代語訳の列を分けるとき |

`ART = 'shapes'` を書いておくと、巻物や角丸枠などの飾りは残したまま、
「先従隗始」用の挿絵（隗と昭王の似顔絵・四コマ漢文）だけを外します。
挿絵ごと使いたいときは `ART = 'all'`。

生徒版の空欄の幅は `《…》` の文字数から自動で決まります。

## 差し込み位置（スロット）の名前

`p1` が 1 枚目（書き下し）、`p2` が 2 枚目（現代語訳）です。

| 名前 | 場所 |
| --- | --- |
| `p1.title` / `p1.instruction` / `p1.name` | 右端の見出し帯・指示文・記名欄 |
| `p1.kanbun.1` 〜 `.10` | 訓読文（白文＋訓点）の各段 |
| `p1.kanbun.1.num` | その段の丸数字 |
| `p1.answer.1` 〜 `.10` | 1 枚目は書き下し文、2 枚目は現代語訳 |
| `p2.answer.4.c1` `.c2` `.c3` | 長い訳を手作業で列分けしてある欄 |
| `p1.note.1.def` / `.supp` | 句法と語注の本文と、その※補足 |
| `p1.note.heading` / `.subheading` | 「句法と語注」「名前・意味・本文の箇所」 |
| `p1.q.1.text` / `.answer` | 設問文と、その解答欄 |
| `p1.q.2.answer.c1` `.c2` | 手作業で左右に分けてある解答欄 |
| `p1.q.3.extra` | 設問の横の小さな補助欄 |
| `p1.source` | 「『十八史略』刪修」 |

`build.py` は content 側に書いたスロットだけを差し替えます。書かなかった
スロットはテンプレートの文字がそのまま残るので、一部だけ直すこともできます。

## 漢詩を載せるとき

テンプレートは散文用に本文の段を 10 段持っています。七言絶句のように
四句しかない教材は、**1・3・5・7・9 段目だけを使い、間の段（2・4・6・8・10）を
空文字にする**と、四句が紙面の幅いっぱいに等間隔で並びます
（`content_sohatsu_hakuteijo.py` がその書き方です）。

詩題は段の番号を空（`'p1.kanbun.1.num': ''`）にすると、丸数字なしの段になります。
作者名と出典は右端の `p1.source` に入れてください。

## 完成版から引き継いだ設定

- 用紙 A4 横／余白 天15・左右16・地14mm、2 セクション（1 枚ずつ）
- 訓読文＝HG正楷書体-PRO 11.5pt、それ以外＝UD デジタル教科書体 N
- 返り点・小書き送り仮名＝下付き文字
- 行間＝1 行（`w:lineRule="auto"` / `w:line="240"`）
- 図形 15 個・VML 11 個・画像 7 点（巻物、角丸枠、隗と昭王の挿絵、四コマ漢文）

### 自動で直したところ

手入力の過程で混ざっていた表記ゆれだけ、テンプレート化の際にそろえました。

- 書体名 `UD デジタル 教科書体 N`（余分な空白）と `… NK` → `UD デジタル教科書体 N`
- 黒 `000000` / `262626` / `2B2B26` → `1A1A1A`
- 赤 `FF0000` → `EE0000`（ファイル内で多数派だった方に統一）

## 確認済みのこと

- `解答版` は先生の完成版と**全スロットで文字が完全一致**
- 図形・VML の数がテンプレートと一致（差し込みで消えない）
- OOXML の要素順序・セル幅の整合性チェックを通過
- 「早発白帝城」は解答版・生徒版とも、はみ出し 0・文字の重なり 0

### テンプレート化のときに直した不具合

先生の完成版を読み取って差し込み直す際、次の 3 つを直しました。
どれも「先従隗始」の版でも起きていたものです。

- ルビが本文と同じ大きさで組まれ、親字の横に大きく並んでしまっていた
  （ルビの大きさは `w:rubyPr/w:hps` が持つのに、ルビ文字側の `w:sz` を
  見ていたため）
- 「マスターＰ186」のような**縦中横（42% に平体をかけた文字）**を
  その欄の基準の書式と取り違え、欄の文字がすべて 42% の幅で組まれていた
- 詩題のように丸数字のない段を、出典欄と取り違えていた

### 先生の完成版で、欄からはみ出している箇所

`verify.py` に完成版をかけると、次の欄で末尾が印刷されていませんでした
（プレビューの書体差の可能性もあります。Word でご確認ください）。

- `p1.title` / `p2.title`（「書き下しプリント①」の最後まで出ない）
- `p1.note.1.def`（使役）・`p1.note.2.def`（抑揚）の 〖訳〗の終わり
- `p1.answer.2`、`p2.answer.2.c1` / `.3.c1` / `.6.c1`
- `p1.q.2.answer` の右半分の小欄（`.c1`）は丸ごと出ないので、
  「早発白帝城」では使わず左半分（`.c2`）にまとめています
